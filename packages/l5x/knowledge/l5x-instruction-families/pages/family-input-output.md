Input/output instructions are one family of the Logix 5000 instruction set. They move data between the controller and I/O modules, produced/consumed tags and other controllers.

The Studio 5000 Logix Designer v37.05 installed help indexes 71 topic pages in this family. The v36.00 help indexes 3 instruction entries in the same family. Both indexes are structural: l5x_docs lists the title, the section and the relative help path, and reads page text from the local help installation at call time. Nothing from the vendor pages ships in this repository.

Representative mnemonics from the family: MSG, GSV, SSV, CIP.

When editing without Studio, connection state matters: check the module or producer status before assuming the data move is the bug.

Call contents with collection "l5x-help-37-05" or "l5x-help-36-00" and pass the revision to list the family section in the installed help index, then search within it for the member you need.
