Select/limit instructions are one family of the Logix 5000 instruction set. They select one value from several candidates or clamp a value inside a band.

The Studio 5000 Logix Designer v37.05 installed help indexes 16 topic pages in this family. The v36.00 help indexes 7 instruction entries in the same family. Both indexes are structural: l5x_docs lists the title, the section and the relative help path, and reads page text from the local help installation at call time. Nothing from the vendor pages ships in this repository.

Representative mnemonics from the family: LIM, SEL, MUX, BAND, BNOT.

When editing without Studio, selection instructions compute all inputs; a division or array access inside an unselected branch still executes and can fault.

Call contents with collection "l5x-help-37-05" or "l5x-help-36-00" and pass the revision to list the family section in the installed help index, then search within it for the member you need.
