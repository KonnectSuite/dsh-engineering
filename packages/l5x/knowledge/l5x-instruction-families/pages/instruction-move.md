MOVE copies one value or a block of elements into a destination, with the destination type converted from the source type.

Operands: source, destination. Before revision 36 the instruction was spelled MOV; from revision 36 the preferred spelling is MOVE and the legacy spelling is accepted for reading. The composer emits the preferred spelling of the project's major revision, and a project that mixes both is reported by the review.

If you are editing an export from an old project, the rungs probably say MOV. Either spelling validates in the catalogue; the L5X output is what differs. Read Engine/mnemonics.ts's rename table for the full legacy-to-modern mapping used by the bundle.
