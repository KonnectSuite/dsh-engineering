HMI instructions are one family of the Logix 5000 instruction set. The HMI button control instruction lets ladder logic hand a button event to an HMI faceplate.

The Studio 5000 Logix Designer v37.05 installed help indexes 2 topic pages in this family. The v36.00 help indexes 1 instruction entry in the same family. Both indexes are structural: l5x_docs lists the title, the section and the relative help path, and reads page text from the local help installation at call time. Nothing from the vendor pages ships in this repository.

Representative mnemonics from the family: HMIBC.

When editing without Studio, the interaction is event-driven; document which tag fires the event so a later edit does not silently break the faceplate.

Call contents with collection "l5x-help-37-05" or "l5x-help-36-00" and pass the revision to list the family section in the installed help index, then search within it for the member you need.
