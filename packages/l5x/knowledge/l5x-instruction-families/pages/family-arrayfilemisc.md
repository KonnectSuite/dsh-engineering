Array file-misc instructions are one family of the Logix 5000 instruction set. They operate on a whole array or file rather than a single element: fill, average, search, sort and statistical reductions.

The Studio 5000 Logix Designer v37.05 installed help indexes 17 topic pages in this family. The v36.00 help indexes 8 instruction entries in the same family. Both indexes are structural: l5x_docs lists the title, the section and the relative help path, and reads page text from the local help installation at call time. Nothing from the vendor pages ships in this repository.

Representative mnemonics from the family: AVE, FAL, FLL, FSC, SRT, STD, SIZE.

When editing without Studio, length operands are counted in elements and are easy to get wrong; confirm the array dimension and that the length keeps the operation inside the array.

Call contents with collection "l5x-help-37-05" or "l5x-help-36-00" and pass the revision to list the family section in the installed help index, then search within it for the member you need.
